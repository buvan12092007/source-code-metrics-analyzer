# Source Code Metrics Analyzer

## Project Overview
This project analyzes Python source code and generates code metrics and semantic warnings.

## Project Structure
- `analyzer.py` — Main source code.
- `samples/` — Sample Python programs and generated metrics results.
- `screenshots/` — Screenshots of program execution.
- `docs/` — Project documentation and Review 3 report.

## How to Run
1. Install Python 3.
2. Open a terminal in the project directory.
3. Run `analyzer.py` using the command required by the project.
4. Review the generated metrics and warnings.

## Demonstration
Execution screenshots are available in the `screenshots/` folder.

## Repository Contents
This repository contains the project source code, sample programs, execution screenshots, and documentation.
